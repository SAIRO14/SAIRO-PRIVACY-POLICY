# SAIRO 개인정보 처리방침

Sairo 서비스의 개인정보 처리방침을 관리·공개하는 저장소입니다.

## 수정 방법

정책 본문은 [index.md](index.md)에서 수정합니다. 수정할 때에는 문서 하단의 버전, 시행일과 [CHANGELOG.md](CHANGELOG.md)의 변경 이력도 함께 갱신하세요.

`main` 브랜치에 변경 사항을 반영하면 GitHub Pages 배포 워크플로가 자동으로 실행됩니다. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 한 번 선택해야 합니다.

배포 주소는 다음 형식입니다.

`https://sairo14.github.io/SAIRO-PRIVACY-POLICY/`

> 이 저장소의 정책 문안은 서비스 운영 사실과 일치하도록 관리해야 합니다. 특히 수탁자, 보유 기간, 외부 서비스 이용, 시행일이 변경되면 정책에 반영하세요.
